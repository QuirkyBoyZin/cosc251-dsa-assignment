# AUPP's COSC251 Assignments

This repository contains all of the source code that will be submitted to the professor for grading as we will implement data structure as the semester goes on

## Purpose

To keep a history of our implementations throughout the semester and most importantly to keep track of how much we are developing in terms of programming.

## Project Structure

We are utilizing a maven project format to get **JUnit 5**  because for every new data structure introduced, we will try to create test cases to validate our implementation.
Here is our folder directory:

```

src/
├── main/
│   └── java/
│       ├── datastructure/  <- new data structure will added here as a package!
│       └── utils/
└── test/
    └── java/
        ├── datastructure/
        └── utils/

```
